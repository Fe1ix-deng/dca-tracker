# DCA Tracker

一款为美股定投设计的投资记录与复盘工具。支持传统 DCA 定额策略和 VA 价值平均策略，数据本地存储，无需注册账号。

**[🌐 在线体验](https://dca.020023.xyz/)** • **[备用地址（需魔法）](https://dca-tracker-steel.vercel.app)**

---

## 为什么需要这个工具

如果你正在美股市场定投，每期都需要记录价格、计算买入股数、追踪收益，传统的表格工具很快就会变得繁琐。DCA Tracker 让这一切自动化：

- **精确计算 VA 策略**：根据目标路径自动计算每期应投金额，无需手动推导公式
- **灵活预算模式**：固定总额分期投完，或持续定投不设终点
- **本地数据存储**：所有数据保存在浏览器，不上传服务器，隐私完全可控
- **一键部署**：零配置部署到 Vercel，3 分钟拥有专属投资记录系统

## 核心功能

### 双策略支持

**DCA 定额策略**：每期投入固定金额，适合追求纪律性执行的投资者

```
第 1 期：投入 $1000
第 2 期：投入 $1000
第 3 期：投入 $1000
...
```

**VA 价值平均策略**：根据目标市值路径动态调整投入金额

```
目标路径：第 n 期市值 = $1000 × n
第 1 期：目标 $1000，实际持仓 $0，建议投入 $1000
第 2 期：目标 $2000，实际持仓 $1100（市场上涨），建议投入 $900
第 3 期：目标 $3000，实际持仓 $1800（市场下跌），建议投入 $1200
```

### 灵活预算管理

- **固定预算模式**：设定总预算 $10,000，分 10 期投完，系统自动计算每期建议金额
- **无限定投模式**：持续记录每期投入，不设终止时间，适合长期定投

### 多资产组合

```javascript
// 示例配置
[
  { ticker: 'QQQ', weight: 60%, currentShares: 0 },
  { ticker: 'VOO', weight: 40%, currentShares: 0 }
]
// 系统自动按权重分配每期投入金额
```

### 自动行情获取（可选）

配置 Twelve Data API Key 后，点击"自动获取价格"即可填入最新市价。未配置或接口失败时自动降级为手动输入，不影响核心功能。

```bash
# .env 文件
TWELVE_DATA_API_KEY=your_api_key_here
```

在 [Twelve Data](https://twelvedata.com/) 免费注册即可获取 API Key。

### 可视化复盘

![Settings Demo](./docs/demo/settings.gif)

- **组合轨迹图**：对比实际市值与目标路径，直观判断执行偏差
- **仓位结构分析**：实时显示各资产当前权重与目标权重的偏离
- **投入节奏**：查看每期投入金额变化，识别执行异常
- **关键指标**：总市值、累计投入、浮动盈亏、剩余预算一目了然

### 数据导出与备份

- **导出 CSV**：所有历史记录可导出为 Excel 兼容格式，方便进一步分析
- **导出 JSON**：完整备份所有计划和历史数据
- **导入 JSON**：一键恢复之前的备份，换设备或清除缓存后可快速恢复

## 使用流程

### 1. 创建第一份计划

进入 **设置** 页面，填写以下信息：

- 计划名称：`2026 美股 VA 定投`
- 预算模式：`固定预算` 或 `无限定投`
- 策略类型：`VA 价值平均` 或 `DCA 定额`
- 总预算：`$10,000`（固定预算模式）
- 总期数：`10`
- 定投频率：`双周` 或 `月`

点击 **添加标的**，配置资产：

```
QQQ  |  纳指 ETF  |  60%  |  现有股数: 0
VOO  |  标普 ETF  |  40%  |  现有股数: 0
```

确保权重总和为 100%，点击 **保存计划**。

### 2. 录入本期操作

进入 **本期操作** 页面：

1. 为每个资产输入当前价格（可手动输入或点击"自动获取"）
2. 查看系统计算的建议买入金额和股数
3. 填写实际买入股数（可与建议不同）
4. 选择决策标签：`正常执行` / `主动低配` / `本期暂停`
5. 添加备注（如："纳指回调，按计划执行"）
6. 点击 **确认记录本期操作**

### 3. 查看总览与历史

- **总览**：查看四大核心指标、组合轨迹图、仓位结构、投入节奏
- **历史**：展开每期详情，支持编辑、删除、导出

## 技术亮点

### 前端架构

- **React 18 + Vite**：快速开发与热更新，构建速度提升 10 倍
- **Tailwind CSS**：原子化样式系统，无冗余 CSS 输出
- **Recharts**：数据可视化图表库，支持响应式与自定义主题

### 数据持久化

所有数据存储在浏览器 `localStorage`，无需后端服务器：

```javascript
// 示例数据结构
{
  plans: [
    {
      id: "plan_001",
      name: "2026美股VA定投",
      strategy: "VA",
      budgetMode: "FIXED",
      assets: [...]
    }
  ],
  records: [
    {
      planId: "plan_001",
      period: 1,
      date: "2026-09-04",
      assets: [...]
    }
  ]
}
```

### 智能降级策略

价格获取失败时自动回退到手动输入，核心功能不受影响：

```javascript
// 伪代码
try {
  price = await fetchFromAPI(ticker)
} catch {
  price = userManualInput()  // 自动降级
}
```

### 拆股/合股处理

支持自动处理股票拆分事件（如 QLD 1:2 拆股）：

- 回溯调整历史股数和价格
- 自动重新计算平均成本
- 原始记录保留，导出时提供调整后口径

### 多语言支持

内置中文/英文界面切换，基于 React Context 实现：

```javascript
const { t, language, setLanguage } = useI18n()
// 一键切换语言，所有文本自动更新
```

## 常见问题

### 数据安全吗？

所有数据保存在你的浏览器本地，不会上传到任何服务器。建议定期在 **历史** 页导出 JSON 备份。

### 支持 A 股吗？

支持 A 股代码识别（如 600519.SS），但自动获取价格功能仅支持美股。A 股用户可手动输入价格。

### 换设备后数据会丢失吗？

数据存储在浏览器本地，换设备前请导出 JSON 备份，在新设备导入即可恢复。

### 可以同时管理多个计划吗？

可以。页面顶部的计划下拉框支持创建和切换多个独立计划。

### VA 策略的目标收益率如何设置？

可以手动设定，也可以点击"自动测算"根据资产历史表现给出建议。这只是目标路径的参数，不代表实际收益。

# VA 操作指标文案澄清设计

## 背景

本期操作页当前使用“VA 目标值”标签。该数值实际表示买入完成后计划内持仓应达到的目标市值，而不是本期建议投入金额。用户容易将目标市值和执行金额混淆，尤其在目标值高于建议投入金额时。

## 目标

- 让用户一眼区分“当前状态”“目标状态”和“执行动作”。
- 保留现有操作页四卡指标布局和响应式行为。
- 不改变 VA 计算公式、历史记录字段或金额计算精度。

## 设计

仅在 VA 策略的操作指标卡中调整显示文案：

| 当前文案 | 新文案 | 辅助说明 |
| --- | --- | --- |
| 计划内持仓价值 | 计划内当前市值 | 不含计划创建前持仓 |
| VA 目标值 | 本期目标持仓市值 | 买入后计划内持仓应达到 |
| 建议买入金额 | 距目标还需投入 | 目标值 − 当前计划内市值 |
| 建议买入股数 | 建议买入股数 | 按当前价格换算 |

“全部持仓价值”保留，用于明确计划外初始持仓与计划内新增持仓的区别。DCA 策略继续使用现有文案，不受本次改动影响。

## 布局与交互

- 保留 `operation-metrics-grid` 四卡结构、排序、断点和卡片样式。
- 辅助说明使用现有次要文本样式，允许在窄屏自然换行。
- 不新增折叠、弹窗或计算详情交互。

## 国际化

为新中文文案增加英文翻译键，并保留旧键以兼容历史记录及其他页面：

- 计划内当前市值: In-plan current market value
- 本期目标持仓市值: Target in-plan market value
- 买入后计划内持仓应达到: Target after this period's purchase
- 距目标还需投入: Amount needed to reach target
- 目标值 − 当前计划内市值: Target minus current in-plan value
- 按当前价格换算: Based on current price
- 不含计划创建前持仓: Excludes holdings before plan start

## 非目标

- 不按自然年度重算年化收益率。
- 不修改 `targetValue`、`requiredAmount` 等记录字段。
- 不改变整数股建议算法或金额显示的取整规则。

## 验证

- 更新 OperationPanel 文案测试，确认 VA 使用新标签、DCA 保持旧标签。
- 运行 OperationPanel 和 VA 计算相关测试。
- 检查桌面四列、平板两列、移动单列布局下文字不溢出。

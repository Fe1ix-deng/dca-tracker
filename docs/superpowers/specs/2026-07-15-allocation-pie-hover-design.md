# 仓位诊断环形图悬停高亮设计

## 目标

让用户在仓位诊断的 ticker 列表中悬停或键盘聚焦任意资产时，能立即识别环形图中的对应扇区。

## 交互

- 列表项的 `mouseenter` 与 `focus` 继续更新既有的活动资产索引。
- 环形图活动扇区在 180ms 内向外扩展 6px。
- 活动扇区保留原色，并在其外缘增加 3px、低透明度的同色环。
- 图表直接悬停时仍由 Recharts 更新活动索引。
- 指针离开列表后维持最后聚焦的资产，保证中心数据和图表不会跳回不确定状态。

## 实现边界

- 修改仅限 `Dashboard` 的活动扇区渲染及必要的可测试标记。
- 使用现有 `activeWeightIndex` 状态和 Recharts `activeShape`，不增加数据模型、持久化状态或第三方依赖。

## 验证

- 组件结构测试覆盖列表和图表共享活动索引、使用自定义活动扇区，以及动画样式标记。
- 执行 Dashboard 定向测试、完整测试套件和生产构建。

# Dashboard Holding Shares Design

## Goal

恢复首页对用户持仓股数的可见性，同时保留当前首页四项概览指标和现有金额计算。

## Design

在 Dashboard 的“仓位诊断”表中新增“持仓股数”列，并为每个 ticker 显示 `plan.assets[].currentShares`。股数按标的逐行展示，不新增跨标的的总股数指标，因为不同证券的股数直接相加缺少可比性。

表头和数据行保持同一列定义，股数使用现有数据值格式化为最多 8 位小数并去除无意义的尾零；缺失或非法值按 `0` 显示。现有权重偏离、市值、报价状态和诊断文案不变。

## Testing

扩展 Dashboard 布局/渲染测试，断言表头包含“持仓股数”、示例 ticker 的股数被渲染，并覆盖小数股数格式。运行对应 Vitest 测试、完整测试集和生产构建。

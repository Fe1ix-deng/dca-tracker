# DCA Tracker 2.7.0

发布日期：2026-10-28（Asia/Taipei）。

- 保存前完整校验草稿；失败保留输入，成功后再导航。保护历史记录关联的资产身份，改善存储失败补偿与备份恢复。
- 逐标的展示行情来源、记录日期和客户端获取时间；刷新失败保留可用参考价，手动输入优先。
- 统一拆合股持仓与历史参考价的估值口径，保留原始交易；正持仓缺可靠价格时不展示完整组合市值及盈亏。
- 统一执行业务日期与备份导入导出，增加到期状态和本地跨日刷新。
- 增加首次创建入口、原生滑杆名称及键盘支持，更新中英文 FAQ、金融与隐私说明，修复窄屏顶栏遮挡。

本版保留既有本地存储键与备份格式，不要求数据迁移。更新前建议导出 JSON 备份。行情为参考信息，客户端获取时间不代表交易所行情时间。

验收采用风险相关的代表性 Chromium 流程；未进行人工读屏或完整浏览器矩阵。localStorage 多键补偿不能保证浏览器故障下的绝对原子性；原始恢复 JSON 不保证可直接正常导入。
